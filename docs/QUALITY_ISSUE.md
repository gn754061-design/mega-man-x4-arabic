# فحص الجودة — نتيجة سلبية مهمة (يجب معالجتها)

تاريخ: 2026-11-13 · أداة: `tools/check_glyphs.py` · `tools/render_text.py`

## 1. العارض المرجعي (reference renderer) — يعمل
محاكاة منطق رسم المحرك من نفس البيانات (الأطلس + الشيفرات + قواعد 20×3 واللفّ):

| الفحص | النتيجة |
|---|---|
| رسائل مُصيَّرة | 104 |
| صفحات | 545 |
| أقصى عرض سطر | **20 خلية** (الحد 20) |
| أسطر تتجاوز الحد | **0** |
| رسائل فارغة | 0 |
| صور | `out/render/dialogue.*.png` |

→ **البنية سليمة**: لا خروج عن الصندوق، لا تجاوز للعرض، لا رسالة فارغة.

## 2. لكن: الأشكال العربية غير مقروءة كفاية
| الفحص | النتيجة | المطلوب |
|---|---|---|
| غليفات موضوعة | 127 | — |
| **بصمات مميِّزة** | **77 فقط** | 127 |
| **مجموعات مكرَّرة** | **35** | 0 |
| **غليفات بحبر ≤ 2** | **7** | 0 |

### أمثلة موثَّقة
```
U+FE83 (ألف مهموزة)      → ink = 0   (فارغ تماماً)
U+FE8D (ألف)              → ink = 0   (فارغ تماماً)
U+002E (نقطة)             → ink = 1
U+060C (فاصلة عربية)      → ink = 1
U+FE85 / U+FE86 / U+FEED / U+FEEE  → بصمة واحدة (و / ؤ / ؤ / ۀ)
U+FEA3 / U+FEA4 / U+FEA7 / U+FEA8  → بصمة واحدة (ت / تـ / ـت / ـتـ)
```

**السبب:** تصغير خط Arial من 8px مع LANCZOS يمحو **النقاط** التي تميّز الحروف
(ب/ت/ث/ن/ي)، فتتوحّد الأشكال أو تختفي.

## 3. الخلاصة الهندسية
- **البنية 100% سليمة** (الحقن، الترميز، الفواصل، العرض).
- **الخط هو نقطة الفشل**: لا يجوز توليد عربية 8×8 من خط TTF مُصغَّر.
- **الحل المطلوب**: خط عربي **8×8 مرسوم يدوياً** (bitmap font) — إما من مجموعة `.bdf`/`.hex`
  جاهزة، أو تصميم يدوي لكل شكل من الأشكال الـ127 (النقاط والنهايات).

## 4. ما تبقّى مفتوحاً
1. **إعادة بناء الخط**: 127 شكلاً مرسومة يدوياً (أو من مصدر bitmap عربي).
2. **تحقّق بصري**: `vision-bridge` غير متاح (timeout) — يلزم فحص بشري أو OCR عربي.
3. **ارتفاع الخلية**: النمط الإرشادي يشير إلى **16 صفاً لكل خلية** (لا 8) — يحتاج تأكيداً
   قبل إعادة الرسم، وقد يمنح ضعف المساحة العمودية.
