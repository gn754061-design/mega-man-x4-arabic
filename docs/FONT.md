# FONT — أطلس خط الحوار (LOAD_U.ARC / 0x10001)

تاريخ: 2026-11-13 · تحليل مباشر للبايت

## 1. الموقع
| البند | القيمة |
|---|---|
| الملف | `ARC/LOAD_U.ARC` (LBA 222) |
| العضو | النوع `0x00010001` — 32,768 بايت |
| المسار المستخرج | `arc/LOAD_U/00010001.bin` |

## 2. الهندسة (مُثبَتة)
| البند | القيمة |
|---|---|
| الأبعاد | 256 × 256 بكسل |
| العمق | 4bpp (16 لوناً، مفهرس) |
| حجم الخلية | 8 × 8 بكسل |
| الشبكة | 32 عموداً × 32 صفاً = **1024 خلية** |
| ترميز البكسل | بايتان لكل 4 بكسلات (high nibble أولاً) |
| خريطة المحارف | رقم المحرف = رقم الخلية مباشرة (`0x000`–`0x3FF`) |

**إثبات:** الخلية `0x53` تُظهر حرف `J` (شريط علوي + ساق يمين + خطّاف سفلي)،
و`0x50` تُظهر `G`، و`0x4B` تُظهر `B`، و`0x4E` تُظهر `E`، و`0x4F` تُظهر `F`، و`0x4D` تُظهر `D`.

## 3. الإشغال
| البند | العدد |
|---|---|
| خلايا مستخدمة | 554 |
| **خلايا فارغة** | **470** |
| أعلى كود مستخدم | `0x2F5` |
| فارغ في `0x000–0x1FF` | 74 |
| **فارغ في `0x200–0x3FF`** | **396** |

**كتلة متصلة مثالية:** `0x200`–`0x3FF` = **396 خلية فارغة متتالية**.

## 4. القرار الهندسي
العربية تحتاج ~130 شكلاً (28 حرفاً × 4 أشكال − غير المتصل + دعجات).
المتاح 396 خلية متتالية → **كافٍ دون توسيع الأطلس ودون تغيير حجم الملف ودون إعادة بناء ISO.**

**التطبيق:** تُكتب الأشكال العربية في الخلايا `0x200`–`0x27F` (128 خلية) أو `0x200`–`0x2FF` (256 خلية).

## 5. ما تبقّى مفتوحاً
1. **RTL**: المحرك يرسم الشيفرات يسار→يمين؛ يجب إدخال العربية **مرتّبة بصرياً** (pre-reversed).
2. **التشكيل السياقي**: يجب تحويل الحروف إلى أشكال العرض (Presentation Forms) قبل الترميز.
3. **العدد/اللاتيني داخل العربية**: يبقى بترتيبه LTR داخل السطر المرئي.
4. **الـwrap**: المحرك يلفّ عند علامة حدّ الكلمة (`0x1000`) بعرض 20 خلية؛ يجب ضبط الأسطر >(20 خلية) لتفادي قصّ الكلمات.
