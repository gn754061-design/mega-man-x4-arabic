# CODEC — ترميز نص Mega Man X4 (مُتحقَّق منه بالكامل)

تاريخ: 2026-11-13 · مرجع: `TeheManX4_Editor` (`ARC.cs`, `TextEntry.cs`) + تحقق على القرص

## 1. حاوية ARC (مؤكدة من `ARC.cs`)
| Offset | الحقل |
|---|---|
| `0x00` | `u32 fileCount` |
| `0x04` | `u32 fileSize` (حجم الملف كاملاً) |
| `0x08` | `{ u32 type, u32 size }` للعضو 0 |
| `0x10 + (i-1)*8` | `{ u32 type, u32 size }` للعضو i>0 |
| `0x800` | بداية بيانات الأعضاء، كل عضو مُصفَّف إلى مضاعف `0x800` |

**تحقّق:** `LOAD_U.ARC` → count=3, size=0x18800=100352 ✓ · `ST0F_U1.ARC` → count=7, size=0x1F800=129024 ✓

## 2. عضو النص (النوع `0x00000015` في `PLxx_U.ARC`)
| الملف | الحملة | عدد الرسائل | أول إزاحة |
|---|---|---|---|
| `ARC/PL00_U.ARC` | X | 55 | `0x6E` |
| `ARC/PL01_U.ARC` | Zero | 49 | `0x62` |

**البنية:** لا يوجد حقل count صريح؛ عدد الرسائل = `first_offset / 2`.
جدول الإزاحات `u16[N]` يبدأ عند `0x00`، وبيانات الرسائل تبدأ عند `first_offset`.

## 3. ترميز الرسالة — u16 لكل محرف
| البت | المعنى |
|---|---|
| `0x8000` | نهاية الرسالة (قد يحمل المحرف الأخير الضمني) |
| `0x2000` | نهاية مربع نص (`\f`) — قد يحمل محرفاً |
| `0x1000` | حدّ كلمة (علامة للالتفاف) |
| `0x0800` | مجموعة ألوان/تنسيق (اسم المرحلة) |
| `0x0FFF` | **رقم المحرف (glyph)** — 0x000–0x7FF = 2048 محرفاً |

## 4. خريطة المحارف النهائية (66 محرفاً، صفر تعارض)
| المدى | المحارف |
|---|---|
| `0x1FF` | مسافة |
| `0x40`–`0x49` | `0`–`9` |
| `0x4A`–`0x63` | `A`–`Z` (`A`=0x4A … `Z`=0x63) |
| `0x64`–`0x7D` | `a`–`z` (`a`=0x64 … `z`=0x7D) |
| `0x83` | `+` |
| `0x84` | `-` |
| `0x85` | `,` |
| `0x86` | `.` |
| `0x87` | `!` |
| `0x88` | `?` |
| `0x8B` | `'` |

**اشتقاق:** من محاذاة 104 رسائل معروفة (`tools/derive_final.py`) → `data/glyph_map.json`.

## 5. نتائج التحقق
| البند | النتيجة |
|---|---|
| رسائل مقارنة | 104 |
| مطابقة تامة | **102 / 104** |
| غير مطابقة | `dialogue.x.054` و`dialogue.zero.048` = `{glyph:38}` غير نصيين (مُتوقَّع) |

**ملاحظتان:**
1. المحرف الأخير في كل رسالة **ضمني** يحمله مُنهِي `0x8000` (مثال `construction.` تُخزَّن `...construction` + `0x8000`).
2. **لا يوجد كود سطر صريح**؛ النص قطعة واحدة، والمحرك يلفّ عند `0x1000` (حدّ الكلمة).
