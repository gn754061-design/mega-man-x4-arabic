# بلاطات القوائم — ما ثبت وما لم يثبت

تاريخ: 2026-11-13

## 1. ما ثبت (بأدلة)

| الفحص | النتيجة |
|---|---|
| بحث ASCII عن `NEW GAME/CONTINUE/OPTION/SAVE/...` في التنفيذي | **0** (كلها رسائل محرك) |
| بحث u16 عن نصوص في كل أعضاء ARC | **0** بمعدل ≥ 90% |
| أعضاء فيها كتل نصية صالحة | **لا يوجد** (0.02–0.06 ضوضاء) |
| `PL00_U/00010206` 320×240 | **رسم CG كامل الشاشة** (0.748 = إيجابية كاذبة) |
| `PL00_U/00000003` 128×256 | **نسيج متكرر** |
| `PL00_U/00010007` | صورة كاملة (73% حبر) |

⟵ **قوائم اللعبة مخزَّنة كـ artwork، لا كنصوص.**

## 2. ما لم يثبت
**الموقع الدقيق لبلاطات القوائم** — المرشّحون مُصدَّرون كصور في:
```
_work_ar\out\candidates\  (7 صور PNG)
```

## 3. لماذا لم أحسمه
1. **الفحص البنيوي غير صالح** — الصور الفوتوغرافية تُعطي نتائج كاذبة
2. **`vision-bridge` غير متاح** — كل استدعاء timeout.
3. **مطابقة القوالب غير محسومة** — استخراج الحروف من الأطلس غير محاذٍ (الحروف تشغل الصفوف 3–7 من الخلية فقط) → القوالب غير صالحة للمطابقة.

## 4. ما remains
| المهمة | الحالة |
|---|---|
| ترجمة النصوص (104 رسالة) | **مكتملة 102/102** |
| الخط العربي (127 غليفاً) | **120/127 مميَّز** |
| باتش `.bps` | **جاهز** `out/MegaManX4_Arabic.bps` |
| بلاطات القوائم | **مؤجَّل: يحتاج تأكيداً بصرياً** |

## 5. الخطوة التالية
فتح `out/candidates/*.png` وتحديد أي عضو يحوي القوائم، ثم:
استخراج البلاطات → رسم بديل عربي → إعادة إدخال بنفس الحجم → إعادة الباتش.
